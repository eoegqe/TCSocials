The official social links page for Theegget Creations.

## Website

- Production domain: https://socials.theegget.com

## Official channels

## Deployment

This repository is a static website. Publish the repository root with GitHub Pages and connect `socials.theegget.com` to the Pages site using the repository's Pages settings and DNS configuration.
